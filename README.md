# Space Raiders 🚀

Space Raiders is a browser-based 2D space shooter built with HTML, CSS, and JavaScript.

Players fight through increasingly difficult waves of enemies, collect power-ups, battle unique bosses, and try to beat their saved high score.

## Features

- Wave-based enemy system
- Boss fight every 3 waves
- Multiple bosses with unique abilities
- Progressive difficulty scaling
- Player health and shield system
- Power-ups including:
  - Rapid fire
  - Triple shot
  - Shield
  - Health recovery
- Enemy and asteroid collision detection
- Persistent high-score system using localStorage
- Dynamic score tracking
- Game over and restart system
- Custom canvas-based graphics and animations

## Boss System

Every third wave introduces a different boss.

### Void Destroyer
Uses spread shots and aimed attacks.

### Nebula Guardian
Activates an energy shield that temporarily blocks player attacks.

### Phantom Wraith
Teleports around the battlefield and launches attacks after teleporting.

### Swarm Emperor
Summons additional enemy ships during the boss fight.

### Solar Tyrant
Launches large radial projectile attacks.

Bosses become stronger as the player progresses through later waves.

| A / Left Arrow | Move left |
| D / Right Arrow | Move right |
| Spacebar | Shoot |

## High Score System

Space Raiders stores the player's highest score using browser `localStorage`.

This allows the high score to remain saved even after refreshing or closing the game.
